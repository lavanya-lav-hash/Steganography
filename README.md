# 🖼️ Image Steganography Project

This project hides secret text inside an image using **Image Steganography**.  
Steganography is a method of securely hiding information within digital media so that the presence of the message is not detected.

---

## 🔍 What This Project Does

- Takes a **normal image**
- Hides **secret text** inside the image
- Produces a **new image** that looks the same to the eye
- Allows users to **decode and retrieve** the hidden message again

---

## ✅ Features

- Simple and user-friendly
- Can hide text inside any image
- Maintains the original image quality
- Secure message encoding & decoding

---

## 🛠️ Tech Stack Used

| Technology / Language | Purpose |
|----------------------|---------|
| **Python** | Logic and Encoding/Decoding |
| **OpenCV / PIL** | Image processing |
| **Tkinter / GUI (if used)** | User interface |

---

## 📌 How It Works (Simple Explanation)

1. Convert image pixels into numeric values  
2. Convert secret text into binary  
3. Slightly modify image pixel values to store the message  
4. Reverse the process to decode hidden message
